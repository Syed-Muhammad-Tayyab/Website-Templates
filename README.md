## 📖 About

**Website Templates** is an open-source collection of hand-crafted front-end templates covering everything from landing pages and portfolios to dashboards and e-commerce UIs. Every template is built with **clean, semantic code**, **modern CSS techniques**, and **smooth micro-interactions** — ready to clone, customize, and ship.

Whether you're a beginner learning HTML/CSS/JS, or a developer who wants a solid starting point instead of building from scratch, this repo has something for you.

---

## ✨ Features

| | |
|---|---|
| 🎨 **Modern UI/UX** | Clean layouts following current design trends — glassmorphism, neumorphism, minimalism |
| 📱 **Fully Responsive** | Mobile-first design tested across breakpoints (mobile, tablet, desktop) |
| ⚡ **Fast & Lightweight** | No bloated frameworks unless needed — optimized load times |
| 🌗 **Dark / Light Themes** | Many templates ship with a built-in theme toggle |
| 🎬 **Smooth Animations** | Scroll reveals, hover effects, and page transitions via CSS & Framer Motion |
| 🧩 **Component-Based** | Reusable sections (navbars, hero sections, cards, footers) you can mix and match |
| ♿ **Accessible** | Semantic HTML and ARIA-conscious markup |
| 🔍 **SEO-Friendly** | Proper meta tags and structured markup out of the box |

## 🛠️ Getting Started

### Clone the repository

```bash
git clone https://github.com/Syed-Muhammad-Tayyab/Website-Templates.git
cd Website-Templates
```

### For plain HTML/CSS/JS templates

Simply open the `index.html` file of any template folder in your browser — no build step required.

### For React / Vite based templates

```bash
cd template-folder-name
npm install
npm run dev
```

## 🤝 Contributing

Contributions are what make the open-source community amazing! If you have a template you'd like to add:

1. **Fork** the repository
2. **Create** your feature branch (`git checkout -b feature/new-template`)
3. **Commit** your changes (`git commit -m "Add: new template name"`)
4. **Push** to the branch (`git push origin feature/new-template`)
5. **Open** a Pull Request

Please make sure your template is responsive, clean, and includes a short description in its own folder.
